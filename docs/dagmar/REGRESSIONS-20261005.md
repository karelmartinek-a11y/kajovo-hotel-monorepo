## Trust and lifetime

Diagnostic content failure never owns voice lifetime, provider output delivery or
operation retry. Invalid URLs are replaced; unknown capture content is discarded.
Safe metadata remains collectable and producer completeness remains truthful.

Explicit memory intent is tied to native committed audio item IDs in the owner's
logical call, to the operation family and target. It expires after five minutes,
eight related audio turns or 8000 characters. Revocation/change of task/success
closes it. Quoted/tool/mail context cannot create intent. Explicit human requests
after mail remain possible. Delayed transcription belongs to its original item.

Task recovery is transient, bounded to 4000 compatible tokens/24000 UTF-8 bytes,
and owned by the authenticated logical call. It restores data, never human consent.
Mutation identities survive provider replacement; sent/uncertain work never gets
a new write identity. Stop/revocation removes transient content. Backend restart
cannot recover private RAM content; durable operation journals remain authoritative.

The five-minute/eight-turn intent bound covers an introduction, three dictated points
and a retry while avoiding unrelated history. At most sixteen original audio turns
are retained for provenance; only bounded task data enters the restored provider.
Whole results are pruned before human clarifications, with an explicit partial-data
marker and surviving original journal identities. The 3800-token/23000-byte data
allowance reserves room for recovery/trust markers within the 4000/24000 context cap.
Mail references are selected only from accepted backend results; candidate/readback/
bypass consent is connection-local. A bounded mail-readiness wait does not gate
generic conversation.
