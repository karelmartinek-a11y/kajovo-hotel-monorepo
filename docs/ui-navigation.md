# Navigace portálu a administrace

Přihlášené stránky obou aplikací používají `packages/ui/src/shell/AppShell.tsx`. Na telefonu, tabletu i desktopu je jedna pevná, vodorovně posuvná spodní řada. Chat je připnutý jako první a ukazuje nepřečtený počet; následují povolené moduly aktivní role a Profil. Portál zachovává rychlé akce nálezu a závady a serverové přepnutí role přes `/api/auth/select-role`. Záhlaví ponechává značku, název stránky a její ovládací prvky; odhlášení používá CSRF chráněný endpoint `/api/auth/logout`.

Administrace používá rolemi filtrované moduly a základní cestu `/admin`; staré postranní menu je nahrazeno společnou spodní řadou. Přihlašovací a servisní stránky používají veřejné rozložení. Aktivní položka navigace je označena také na podstránkách.

Vizuální testy portálu a administrace pořizují snímky testovaných přihlášených sekcí pro desktop, tablet a telefon. Administrátorské vizuální scénáře běží s jedním Playwright workerem, aby jejich souběžné načítání modulů nevyčerpalo pool testovací databáze; rozsah scénářů a viewportů zůstává stejný. Admin smoke používá Python 3.11 pro testovací API. Oba weby mají jednu pevnou spodní navigaci: Chat s počtem nepřečtených, dostupné moduly podle role a Profil; lišta se při nedostatku šířky posouvá vodorovně. Portál zachovává rychlé akce pokojské, ikonu odhlášení a značku. Chat seznam a badge obnovuje každých 10 s, otevřenou historii každé 3 s, při skrytém panelu obnovování pozastaví. Snímky běžných provozních dat se ukládají jako výstup Playwright běhu mimo verzované zdrojové soubory.
