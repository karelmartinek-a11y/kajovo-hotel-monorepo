# Historický host hlasu

Tento archiv uchovává původní Hotel adaptéry a testy odstraněného hotelového
hlasového API. Nejde o aktivní runtime ani test aktuálního CML hlasu. Původní
úplný stav je v Git revizi 19971b80be6e8c633ae770382217e38eee619123.

Aktivní nástupce a jeho kvalifikace patří do repozitáře kajovocmlnglite,
`voice/`, `checks/voice.test.mjs` a `checks/voice-browser.test.mjs`.
Hotel samostatně ověřuje nedostupnost starého hlasového API a přesměrování.
Offline diagnostické archivy a produkční historická data se nemažou.
